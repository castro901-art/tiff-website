# Tiff AI static website

This is a redesigned static website for Tiff and Trendify. The ZIP is the source of truth for the site's existing pages and concepts. The separate Trendify Academy files were not used.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server. There is no build step, package manager or framework. All navigation uses relative HTML paths, and `index.html` is at the site root for GitHub Pages compatibility.

## Before publishing

Confirm these details with Trendify and update the relevant pages first:

- A real contact email or official contact URL.
- Official app, web, Telegram, Instagram and WhatsApp destinations, plus which channels are currently active.
- Current product availability and confirmed feature scope for Tiffbot, Super Computer and TiffTeams.
- TAM's current status, language coverage, preferred community and language names, and any approval or partnership wording.
- Any dated announcements and current WhatsApp or plan terms.
- Whether to keep Google Fonts externally hosted or provide self-hosted font files. The privacy page currently notes the Google Fonts request.

Channel names and TAM areas on the site are identified as unverified source material or work in progress. Do not interpret them as a guarantee of availability, model coverage, partnership or community endorsement. No facts were verified from the inaccessible reference sites.

The site has not been deployed. GitHub Pages remains disabled, and no DNS or hosting settings were changed.
